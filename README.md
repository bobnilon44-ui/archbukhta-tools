# АрхБухта — калькуляторы для ремонта и налогов

Статический сайт (PWA) с бесплатными онлайн-калькуляторами. Зарабатывает на рекламе РСЯ и партнёрских ссылках.

## Что есть
| Страница | Калькулятор |
|---|---|
| `tile.html` | Плитка (пол/стены, шов, запас, упаковки, клей) |
| `wallpaper.html` | Обои (рулоны с учётом раппорта и проёмов) |
| `laminate.html` | Ламинат, подложка, плинтус |
| `paint.html` | Краска для стен и потолка, банки, грунтовка |
| `concrete.html` | Бетон для плиты и ленточного фундамента, цемент, песок, щебень |
| `plaster.html` | Гипсовая и цементная штукатурка в мешках |
| `brick.html` | Кирпич (одинарный/полуторный/двойной), раствор, поддоны |
| `gasblock.html` | Газобетонные блоки, кубы, клей |
| `insulation.html` | Утеплитель: слои и упаковки |
| `npd.html` | Налог самозанятого (4% / 6%, вычет 10 000 ₽) |
| `usn.html` | Налоги и взносы ИП на УСН 6% и 15% (значения 2026 года) |
| `ndfl.html` | НДФЛ по прогрессивной шкале, зарплата на руки и обратно |
| `vacation.html` | Отпускные по среднему заработку |
| `sick.html` | Больничный 2026 (стаж, предельные базы, МРОТ) |
| `property.html` | Имущественный вычет за жильё и проценты по ипотеке |
| `mortgage.html` | Ипотека: платёж, переплата, нужный доход |
| `credit.html` | Кредит: аннуитет и дифференцированный, график платежей |
| `deposit.html` | Вклад с капитализацией, пополнением и налогом на проценты |
| `alimony.html` | Алименты на 1, 2, 3+ детей |

Сборка не нужна: обычные HTML, CSS и JS.

## Запуск локально
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000

## Как подключить монетизацию
Все настройки собраны в начале файла `assets/app.js` (объект `CONFIG`).

1. **Реклама РСЯ.** Опубликуйте сайт на своём домене и добавьте его в partner.yandex.ru.
   После одобрения создайте блоки и впишите их ID (`R-A-...`) в `CONFIG.yandexAds.blocks`, затем поставьте `enabled: true`.
2. **Партнёрские ссылки.** Зарегистрируйтесь в Admitad или Advcake, либо в партнёрских программах банков.
   Вставьте ссылки в `CONFIG.partners`.
3. **Аналитика.** Вставьте счётчик Яндекс Метрики в `<head>` каждой страницы (там оставлено место комментарием).
4. **SEO.** Замените `ВАШ-ДОМЕН.ru` в `robots.txt` и `sitemap.xml`. Добавьте сайт в Яндекс Вебмастер и Google Search Console.

## Публикация
Сайт публикуется на GitHub Pages автоматически при каждом изменении в ветке `main`
(`.github/workflows/pages.yml`).

Первый запуск:
1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Влейте изменения в `main`. Через 1–2 минуты сайт откроется по адресу
   https://bobnilon44-ui.github.io/archbukhta-tools/

### Свой домен (нужен для РСЯ)
1. Купите домен `.ru` (reg.ru, nic.ru и т. п.).
2. У регистратора добавьте DNS-запись `CNAME` для `www` → `bobnilon44-ui.github.io`
   и записи `A` для корня домена: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. Settings → Pages → Custom domain: впишите домен и включите **Enforce HTTPS**.
4. Замените `ВАШ-ДОМЕН.ru` в `robots.txt` и `sitemap.xml`.

## Как добавить калькулятор
Скопируйте любую страницу и поменяйте форму и функцию в `autoCalc(...)`.
Добавьте плитку в `index.html` и в блоки «Другие калькуляторы», адрес в `sitemap.xml` и файл в список `FILES` в `sw.js` (и увеличьте версию `CACHE`).

> Налоговые ставки и лимиты меняются. Проверяйте их в начале каждого года (константы в `usn.html`, `npd.html`, `ndfl.html`, `sick.html`, `property.html`).
